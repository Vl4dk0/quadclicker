# QuadClicker

Click anywhere using your keyboard.

[Download](https://github.com/Vl4dk0/quadclicker/releases/latest) · [Install and build](INSTALLATION.md)

| Key | Action |
| --- | --- |
| Fn+Space or Mission Control button | Open or close overlay |
| U / I / J / K | Select top left / top right / bottom left / bottom right quarter |
| H or Backspace | Go back one rectangle |
| Shift+H or Shift+Backspace | Reset to the whole display |
| Enter | Click the centre dot; keep selection |
| Escape or other key | Hide overlay |

Choose **Activate** from the menu as another way to start. Navigation uses physical key positions, with up to **nine subdivisions**. Shift or Fn alone keeps the overlay open; other keys pass through. Choose **Quit** from the menu to exit.
