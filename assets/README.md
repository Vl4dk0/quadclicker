# QuadClicker icon

`QuadClicker.png` is the 1024×1024 transparent source. `QuadClicker.icns` contains standard macOS 16, 32, 128, 256, and 512 point sizes at 1× and 2× resolution. The app bundle uses the ICNS file; its menu bar symbol is separate.

Generated with the built-in imagegen tool, then resized and packaged with macOS `sips` and `iconutil`. The generated artwork was inspected at full size and the packaged 32×32 size.

## Generation prompt

Use case: logo-brand. Asset type: production macOS application icon for QuadClicker, a keyboard-driven recursive quadrant screen selector that clicks a midpoint. Create a single 1024x1024 square icon PNG. A refined, minimal macOS rounded-square app tile, dark deep navy with a subtle blue-teal tonal gradient. Inside, one strong geometric screen-square divided into four quadrants by clean thick lines; the upper-right quadrant is highlighted teal and contains one smaller selected square outline, with a single bright midpoint dot. Make the geometry lucid and the silhouette immediately legible at 32px. Flat polished vector-like graphic with very restrained depth, precise balanced strokes, generous internal spacing. Tile occupies approximately 88 percent of canvas width and height with symmetrical margins. Genuine transparent background outside the rounded-square tile. No text, no letters, no mouse arrow, no realistic device frame, no tiny embellishments, no ornamental grids, no strong glow, no drop shadow outside tile.
